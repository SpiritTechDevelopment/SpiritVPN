# FAQ - Часто задаваемые вопросы

## Общие вопросы

### Что такое SpiritVPN?

SpiritVPN - это VPN-сервис с интеграцией в Telegram. Пользователи могут покупать подписки и управлять своим VPN прямо через Telegram бота, без необходимости устанавливать дополнительные приложения или посещать веб-сайты.

### Какие протоколы VPN используются?

Мы используем WireGuard - современный VPN протокол, который обеспечивает:
- Высокую скорость (быстрее OpenVPN и IPSec)
- Отличную безопасность
- Простоту настройки
- Низкое энергопотребление

### Какие платежные системы поддерживаются?

- ЮKassa (карты РФ)
- Stripe (международные карты)
- Криптовалюты (планируется)
- Telegram Stars (планируется)

## Технические вопросы

### Какие операционные системы поддерживаются?

**Клиенты:**
- Windows 10/11
- macOS 11+
- Linux (Ubuntu, Debian, Arch и др.)
- iOS 15+
- Android 8+

**Серверы:**
- Ubuntu 20.04+
- Debian 11+
- CentOS 8+

### Сколько устройств можно подключить одновременно?

Зависит от тарифного плана:
- Basic: 1 устройство
- Premium: 5 устройств
- Enterprise: неограниченно

### Какая скорость соединения?

Скорость зависит от тарифа и сервера:
- Basic: до 50 Мбит/с
- Premium: неограниченная (зависит от сервера)
- Средняя скорость на premium серверах: 200-500 Мбит/с

### Есть ли ограничения по трафику?

Нет, все тарифы предоставляют безлимитный трафик.

## Разработка

### Как начать разработку?

1. Клонируйте репозиторий
2. Установите Go 1.21+
3. Скопируйте `.env.example` в `.env`
4. Запустите `make deps && make build`
5. Настройте PostgreSQL и Redis
6. Запустите `make run-api`

### Как добавить новый эндпоинт в API?

1. Добавьте handler в `internal/api/handlers/`
2. Зарегистрируйте route в `internal/api/server.go`
3. Обновите документацию в `docs/API.md`
4. Добавьте тесты

### Как добавить новую команду в бота?

1. Добавьте handler в `internal/bot/handlers/`
2. Зарегистрируйте команду в `handleMessage()`
3. Добавьте описание команды в BotFather
4. Обновите документацию

### Где хранятся логи?

- Docker: `docker-compose logs <service>`
- Systemd: `/var/log/syslog` или `journalctl -u <service>`
- Файлы: `logs/` директория (если настроено)

## База данных

### Какая БД используется?

PostgreSQL 14+ для основных данных и Redis для кеширования/сессий.

### Как запустить миграции?

```bash
# Автоматически при запуске API сервера
go run ./cmd/api-server/main.go

# Или через специальную команду
make migrate-up
```

### Как сделать backup базы данных?

```bash
# Вручную
pg_dump -U spiritdb spiritdb > backup.sql

# Восстановление
psql -U spiritdb spiritdb < backup.sql

# Автоматический backup (см. DEPLOYMENT.md)
```

## Telegram бот

### Как получить токен бота?

1. Напишите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

### Как настроить платежи в Telegram?

1. Свяжитесь с [@BotFather](https://t.me/BotFather)
2. Выберите бота и настройте Payment provider
3. Для ЮKassa нужен Merchant ID

### Бот не отвечает. Что делать?

1. Проверьте токен в `.env`
2. Проверьте логи: `docker-compose logs bot`
3. Убедитесь, что бот запущен: `docker-compose ps`
4. Проверьте подключение к БД

## VPN сервер

### Как добавить новый сервер?

1. Разверните сервер в новой локации
2. Установите VPN компонент
3. Добавьте сервер в БД:
```sql
INSERT INTO vpn_servers (name, host, port, public_key, location, is_active)
VALUES ('Germany-2', '45.123.45.68', 51820, 'public_key', 'Frankfurt', true);
```

### WireGuard не запускается. Что делать?

1. Проверьте, загружен ли модуль ядра:
```bash
lsmod | grep wireguard
```

2. Загрузите модуль:
```bash
sudo modprobe wireguard
```

3. Проверьте права доступа к `/dev/net/tun`

### Как посмотреть активные соединения?

```bash
sudo wg show
```

### Клиенты не могут подключиться. Решение?

1. Проверьте файрвол:
```bash
sudo ufw allow 51820/udp
```

2. Проверьте IP forwarding:
```bash
sysctl net.ipv4.ip_forward
# Должно быть 1
```

3. Проверьте iptables правила

## Безопасность

### Насколько безопасен SpiritVPN?

- WireGuard использует state-of-the-art криптографию
- ChaCha20 для шифрования
- Curve25519 для обмена ключами
- BLAKE2s для хеширования
- No logs policy

### Хранятся ли логи активности?

Мы храним только:
- Статистику трафика (для биллинга)
- Время последнего подключения
- Не храним: какие сайты посещались, реальный IP

### Как защищены платежные данные?

- Мы не храним данные карт
- Все платежи через PCI DSS сертифицированные провайдеры
- TLS шифрование всех соединений

## Производительность

### Сколько пользователей может обслужить один сервер?

Зависит от конфигурации:
- VPS 2 CPU / 2GB RAM: ~500-1000 пользователей
- VPS 4 CPU / 8GB RAM: ~2000-5000 пользователей
- Dedicated 8 CPU / 16GB RAM: 10000+ пользователей

### Как оптимизировать производительность?

1. Используйте Redis для кеширования
2. Включите connection pooling в PostgreSQL
3. Настройте CDN для статики
4. Используйте gRPC между сервисами
5. Масштабируйтесь горизонтально

### Почему медленное соединение?

1. Попробуйте другой сервер
2. Проверьте свой ISP
3. Убедитесь, что сервер не перегружен
4. Проверьте MTU настройки

## Биллинг и платежи

### Как работает автопродление?

При включенном автопродлении:
1. За 3 дня до окончания подписки отправляется напоминание
2. В день окончания списывается оплата
3. Подписка автоматически продлевается
4. Если оплата не прошла - подписка деактивируется

### Можно ли вернуть деньги?

Да, в течение 7 дней без объяснения причин. Средства возвращаются на ту же карту.

### Как работает реферальная программа?

- Пригласите друга - получите 20% от его первой оплаты
- Друг получает скидку 10% на первую подписку
- Выплаты раз в месяц

## Проблемы и решения

### "Failed to connect to database"

1. Проверьте, запущен ли PostgreSQL:
```bash
docker-compose ps postgres
```

2. Проверьте credentials в `.env`

3. Проверьте подключение:
```bash
psql -h localhost -U spiritdb -d spiritdb
```

### "Invalid bot token"

1. Убедитесь, что токен правильный
2. Проверьте, нет ли лишних пробелов
3. Создайте нового бота если токен скомпрометирован

### "Port already in use"

Измените порт в `.env` или остановите конфликтующий сервис:
```bash
sudo lsof -i :8080
sudo kill -9 <PID>
```

### Медленная работа API

1. Проверьте CPU/RAM сервера
2. Включите Redis кеширование
3. Оптимизируйте запросы к БД
4. Увеличьте connection pool
